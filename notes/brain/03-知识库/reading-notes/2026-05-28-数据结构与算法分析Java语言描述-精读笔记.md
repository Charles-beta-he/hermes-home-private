## 10 条关键概念 / 例子卡

1. **增长率优先于机器常数**：第2章把算法分析放在抽象模型上，阅读时要把“输入规模 n 的增长曲线”与“本机跑得快慢”分开记录。
2. **递归必须同时有终止条件与规模缩小**：第1章递归简论可作为所有分治/回溯/树遍历的共同检查表。
3. **ADT 是接口承诺，不是具体容器**：第3章从表、栈、队列切入，重点是操作语义、复杂度与实现替换边界。
4. **ArrayList vs LinkedList 是访问模式选择题**：第3章将 Java Collections 与实现连接起来；随机访问、插入删除、迭代器失效需要分开评估。
5. **二叉查找树需要平衡假设**：第4章 BST 的 contains/findMin/insert/remove 很直接，但平均情况不能替代最坏情况治理；AVL/伸展树/B树是不同平衡策略。
6. **散列表的核心风险是冲突与负载因子**：第5章的分离链接、线性/平方探测、双散列、再散列分别对应不同冲突治理方式。
7. **堆是“只关心最值”的局部有序结构**：第6章优先队列不维护全序，只保证 deleteMin / insert 等操作的高效性，适合调度、Top-K、事件模拟。
8. **排序算法选择要看数据规模、稳定性、内存、外部存储**：第7章从插入排序到外部排序说明“最快平均复杂度”不是唯一标准。
9. **并查集把连通性维护变成近似常数成本**：第8章按秩合并 + 路径压缩适合动态等价、连通分量、Kruskal MST 前置结构。
10. **图算法是工程依赖/路由/调度的通用语言**：第9章拓扑排序、Dijkstra、Prim/Kruskal、DFS 应用分别映射到依赖排序、路径规划、连接成本、结构诊断。
11. **动态规划要求明确状态与转移，而不是“递归加缓存”口号**：第10章矩阵链乘、最优 BST、所有点对最短路径是后续刷题/系统优化的模板。
12. **摊还分析适合解释批量性能承诺**：第11章提醒工程上不要只看单次操作尖峰，还要证明一段操作序列的总成本。

## 3 个实践练习

1. **复杂度校准练习**：实现最大子序列和的三种版本（暴力 O(n²/³)、分治、线性扫描），用同一组随机数组记录运行时间曲线，并写出复杂度解释。
2. **容器替换练习**：实现一个 LRU/最近访问列表原型，分别用 `ArrayList`、`LinkedList`、`HashMap + 双向链表`，记录每种设计的关键操作复杂度与适用边界。
3. **图依赖练习**：用拓扑排序检查一个小型任务池 DAG 是否有环；再用 Dijkstra/无权 BFS 对“任务依赖距离”做示例查询，沉淀到 Hermes taskpool 学习案例。

## 可落地到项目 / 技能树的应用点

**Hermes taskpool / local-brain 技能树应用**：把第9章图算法与第3/5章容器模型合并为一个“任务池依赖健康”学习/实践模块：
