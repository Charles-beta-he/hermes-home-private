# 预算耗尽后自动接力与回退策略 — 实施设计

## 当前状态

`run_agent.py` L12205: 预算耗尽后给一次 grace call，然后退出循环返回 final_response。
无 relay/continuation 机制，对话直接终止。

## 设计方案

### 1. ContinuationPacket 数据结构

```python
@dataclass
class ContinuationPacket:
    reason: str                    # "budget_exhausted" | "max_iterations"
    summary: str                   # 模型在 grace call 中生成的摘要
    messages_snapshot: list[dict]  # 完整消息历史 (截断到最近 N 条)
    tools_used: list[str]          # 本轮使用的工具列表
    pending_tasks: list[str]       # 未完成的子任务 (从 final_response 提取)
    budget_used: int               # 已用迭代次数
    budget_max: int                # 最大迭代次数
    session_id: str                # 当前会话 ID (用于 --resume)
    created_at: str                # ISO timestamp
```

### 2. 接力触发逻辑 (run_agent.py)

在 `_turn_exit_reason == "budget_exhausted"` 时:

```python
if _turn_exit_reason == "budget_exhausted" and final_response:
    packet = ContinuationPacket(
        reason="budget_exhausted",
        summary=final_response,
        messages_snapshot=self._get_recent_messages(max_count=20),
        tools_used=list(self._tools_used_this_turn),
        pending_tasks=extract_pending_tasks(final_response),
        budget_used=self.iteration_budget.used,
        budget_max=self.iteration_budget.max_total,
        session_id=self.session_id,
        created_at=datetime.now().isoformat(),
    )
    # 写入磁盘供后续接力使用
    packet_path = self._save_continuation_packet(packet)
    return {
        "final_response": final_response,
        "continuation_packet": packet,
        "continuation_path": str(packet_path),
        "needs_relay": True,
    }
```

### 3. 接力执行 (cli.py / gateway)

CLI 层检测 `needs_relay` 标志:

```python
result = agent.run_conversation(user_message)
if result.get("needs_relay"):
    packet = result["continuation_packet"]
    # 选项 A: 自动接力 (用户确认后)
    if auto_relay_enabled:
        new_agent = create_agent_with_continuation(packet)
        relay_result = new_agent.run_conversation(
            f"Continue from previous session. Summary: {packet.summary}"
        )
    # 选项 B: 提示用户手动接力
    else:
        print(f"Budget exhausted. Resume with: hermes --resume {packet.session_id}")
```

### 4. 回退策略

当接力失败时:

1. **降级为摘要返回** — 直接返回 grace call 的 final_response
2. **保存会话** — 写入 session DB，用户可 --resume 继续
3. **通知用户** — 明确告知预算耗尽，提供恢复路径

### 5. 实施步骤

| Step | 改动 | 验证 |
|------|------|------|
| 1 | 添加 ContinuationPacket dataclass | 单元测试 |
| 2 | 在 budget_exhausted 分支创建 packet | 集成测试 |
| 3 | 返回值增加 continuation_packet 字段 | 接口测试 |
| 4 | CLI 层检测 needs_relay 并提示用户 | 手动测试 |
| 5 | (可选) 自动接力逻辑 | 端到端测试 |

### 6. 保守策略

- 默认不自动接力，只提示用户
- 自动接力需要用户显式开启 (`auto_relay: true` in config)
- 接力次数上限 = 1 (防止无限接力)
- 接力会话继承原会话的 session_id lineage
