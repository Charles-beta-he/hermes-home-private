# 2026-05-07 可恢复多模型认证系统长期目标落地

## Evolution Event

将 Hermes multi-model discussion 的长期目标从“延长 discussion 阶段”提升为“可恢复多模型认证系统”。

## Before

- discussion 长跑受 foreground timeout 影响；
- partial run 只留下 merged_plan；
- 无 discussion_result 时只能 weak consensus；
- TaskCreate -> ralph 等高风险功能缺少可恢复 ratification 基础设施。

## After

- RMCS 成为 P0 基础设施项目；
- TaskCreate -> ralph 延后；
- 先做 checkpoint/audit/resume/background-safe runner；
- certification 以 manifest 为准，不以模型同意为准。
