# 错误分类与复盘循环

## 常见错误类型

| 类型 | 信号 | 处理 |
|---|---|---|
| 观测错误 | 没读文件/没搜/没跑命令 | 补 evidence |
| 推理错误 | 证据支持但结论跳跃 | 写 disagreement ledger |
| 执行错误 | 改错文件/漏同步 | sync/reindex/search/test |
| 记忆错误 | WIP 进入长期记忆 | 删除/迁移到 task log |
| 治理错误 | 规则本身导致坏结果 | 二阶审计 rule |

## 复盘闭环

```text
失败信号 → 分类 → 根因 → 修复 → 验证 → 写入 skill/日志/本地大脑 → 后续审计
```
