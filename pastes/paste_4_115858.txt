  4. Apply 期 race condition                                      
                                                                                          
  你没提的: Hermes 是 24/7 跑的, evolve cron 触发时可能正在执行别的 task。skill_edit
  中途改 skill 文件 → 正在跑的那条 task 行为未定义。                                      
                                                                  
  加强: apply-plan.sh 前置drain 阶段:                                                     
                                                                  
  # apply-plan.sh 开头                                                                    
  hermes config set scheduler.accept_new false   # 拒收新 task                            
  sleep 30                                                                                
  WAITED=0                                                                                
  while [ $(hermes sessions list --status running --json | jq 'length') -gt 0 ]; do       
    sleep 5                                                                               
    WAITED=$((WAITED + 5))                                                                
    if [ $WAITED -gt 600 ]; then                                                          
      echo "ABORT: drain timeout, in-flight tasks not finishing"  
      hermes config set scheduler.accept_new true                                         
      exit 1                                                                              
    fi                                                                                    
  done                                                                                    
  # ... apply changes ...                                         
  hermes config set scheduler.accept_new true                                             
   
  或者更简单: evolve cron 挑凌晨低峰 (3:00 AM), 业务规模小可以接受。
