# 机会与假设

## 机会

小游戏适合“小玩法内核 + 多内容包”的实验结构：一次验证核心交互，多次验证题材、文案和关卡参数。AI 的主要价值应是降低候选内容和研发工作包的边际成本，而不是替代规则正确性与真实用户验证。

## 核心假设

1. “线路整理”能在 30–60 秒内形成理解—操作—反馈闭环。
2. 数据中心/太空站/城市复电等内容包可共享同一玩法内核。
3. 内容差异能够带来有效实验，而不仅是视觉换皮。
4. 激励视频触点可以保持自愿、可恢复且不破坏公平性。
5. 低成本模型在受限 schema 与确定性门禁下可以承担大部分内容候选任务。

## 高风险假设

- 玩家是否觉得有趣、是否愿意复玩：必须通过真实试玩验证。
- 抖音/微信当前审核与广告资格：必须查官方文档和账号状态。
- 留存、广告完成率和收入：必须上线后读取真实指标。
- 内容包差异是否足够：需要重复度和用户感知实验。

## 最小实验顺序

1. 纸面规则与离线模拟；
2. 单关卡可玩闭环；
3. 三内容包盲测，确认玩法结果一致；
4. 5–10 人可理解性/乐趣试玩；
5. 平台 SDK 沙箱；
6. 获得授权后再考虑送审与小流量实验。
