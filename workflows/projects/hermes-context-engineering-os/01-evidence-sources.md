# Evidence Sources and Core Works

## Direct Context Engineering

1. Mei et al. — A Survey of Context Engineering for Large Language Models
   URL: https://arxiv.org/abs/2507.13334
   Claim: CE systematically optimizes the information payload provided to LLMs; taxonomy includes retrieval/generation, processing, management, RAG, memory, tool reasoning, and multi-agent systems.

2. coleam00/context-engineering-intro
   URL: https://github.com/coleam00/context-engineering-intro
   Claim: AI coding reliability improves when documentation, examples, rules, PRPs, and validation gates are assembled as task context.

3. SmoothAgent
   URL: https://arxiv.org/abs/2607.00151
   Claim: long-horizon agents need context transformation strategies such as offloading, reduction, isolation; runtime can precompute transformations and reduce TTFT.

## Evidence Handling Rule

Each material claim must map to a source. A source proves only its own claim; a local summary is not a substitute for the source.
